# AI evaluation module

このモジュールは AI 作成の予約、定期実行、結果を管理します。

画面操作では `AiJob` を予約するだけで、LLM は呼びません。5分ごとの定期実行が Hub 基盤の LLM を呼び、結果を保存します。外部の LLM は直接呼びません。

1テナントにつき1日50件まで予約できます。利用状況は `AiJob` から、日本時間の日ごとの成功・失敗・待ち・実行中と種類別の回数を集計します。

氏名、メール、社員番号は LLM に送りません。指示や本文をログへ出しません。

育成のヒントは `ADMIN` と担当範囲内の `MANAGER` だけが閲覧、作成できます。AI の利用状況と前提スキルの提案は `ADMIN` だけが利用できます。
