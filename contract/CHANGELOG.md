# 契約の変更の記録

基盤が Hub に約束するもの（proto、入口のヘッダ、CSRF の方式、Claude Code 向けの決まり、CI のひな形、共通 chart の設定の書式、画面の見た目の決まり）の、版ごとの変更。版の決まりは `guide/README.md` §11。

| 版 | 内容 |
|---|---|
| 0.20.0 | 画面の経路（`/<接頭辞>` の下）への書き込み（POST / PUT / PATCH / DELETE）は、CSRF のトークンが無い・合わなくても、`Origin` のホスト（ポート込み）が要求のホストと同じなら入口が通すようにした（Next.js の Server Actions など、`X-CSRF-Token` を付けられない書き込みのため。§3.4）。API の経路（`/api/<接頭辞>`）は今までどおりトークンが要る。LLM の口の `ResourceExhausted` のメッセージに含む語（`busy` / `batch window` / `daily quota` / `external daily quota`）を変えないことを書いた（§4.9）。devkit も同じ判定にした。Hub の側ですること: 取り込み直す。Server Actions など画面の経路への書き込みは、トークン無しでも `Origin` が同じなら通る。proto の変更なし |
| 0.19.0 | LLM の口（`Generate`）に任意の項目 `temperature` / `top_p` を足した（足すだけ）。出力の長さの上限（1 回 2,048 トークン、入力と合わせて 8,192 トークン）と、定期実行で RLS の外から対象を引く `SECURITY DEFINER` の関数の決まりを書いた（§4.9 / §6.1）。Hub の側ですること: 取り込み直す。LLM を使う Hub は proto からクライアントを作り直す（今の呼び出しはそのまま動く） |
| 0.18.1 | 説明の追加。Hub を登録する・初めて本番に出すときに基盤の担当がすること、Hub のチームがすること、依頼と質問の窓口（hub-platform の issue のテンプレート、ラベル `hub-request`）を利用ガイド §6.4 にまとめた。DB の自動の用意は prod でも有効になった（§6.1）。Hub の側ですること: 取り込み直す。基盤への依頼・質問は §6.4 の窓口から出す。proto・ヘッダの変更なし |
| 0.18.0 | 通知を送る口（`SendNotification`）に任意の項目 `kind` / `category` / `priority` / `actor_user_id` / `ref_id` を足し、`body` を任意にした（足すだけ）。画面は `GET /api/v1/notifications/unread-counts` の `byCategory` で、製品・分類ごとの未読の数を取れる（§4.8）。`tenant.v1` の写しに `ListAvailableProducts` が入った（基盤の内部用。Hub 向けのポートでは呼べない）。devkit も同じ検査にした。Hub の側ですること: 取り込み直す。通知を使う Hub は proto からクライアントを作り直す（今の呼び出しはそのまま動く）。種類ごとの印は、まだ Reporthub の通知だけ |
| 0.17.4 | 見た目の決まりの色の使い方を直した（値は変えていない）。誤りのある入力欄の枠は `--hub-color-danger`（`danger-border-strong` は白との比 1.9 で枠には足りない）。失敗のトーストの地は `--hub-color-danger-text`、成功のトーストの地は `--hub-color-success-text`（白い文字との比 4.5:1 以上）。タスクハブの指摘から。Hub の側ですること: 同じ使い方にそろえる |

| 0.17.2 | 見た目の決まりで、主の色（`--hub-color-primary-50`〜`950` と `--hub-color-text-on-primary`）だけは製品ごとに上書きしてよいことにした（`design/README.md`「主の色」。主ボタンのコントラスト比 4.5:1 以上）。ほかの変数は今までどおり共通。Hub の側ですることは無い（変えたい Hub だけ上書きする）。proto・ヘッダの変更なし |

| 0.16.1 | 公開している口の一覧に「集めた結果」の表を足した（Hub ごとの状態、内容を読めた日、Hub の側ですること）。`scripts/hub-contracts.sh <製品名>` にも出る。Hub の側ですること: 取り込み直す。proto・ヘッダの変更なし |
